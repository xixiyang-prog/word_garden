# 字有进步 · 错字小花园

一个不需要安装依赖、不需要账户的中文错别字复习小游戏。

## 打开

直接双击本目录的 index.html，推荐使用较新的 Edge、Chrome、Firefox 或 Safari；直接读写本地题库文件推荐桌面版 Edge / Chrome。保持 index.html、styles.css、app.js、images.js、storage.js 和 worksheet.js 在同一个目录，不需要启动服务器。也可以把这些文件部署到静态网站供手机访问。

## 使用

1. 默认提供 12 组示例题供体验。在“我的错字本”可移除尚未练习的示例。
2. 点击“添加易错字”，填写正确写法，选择常见错写的“文字 / 图片”录入方式，另可填写记忆提示。程序不会自动生成或校对错写，请由老师审核。
3. 支持批量录入，每行：正确写法 | 常见错写 | 提示。也支持 Tab 分隔。提示选填。整批校验成功后才加入，重复的正确/错写组合会跳过。
4. 文字题：“火眼金睛”从两种写法中选择；“错字修理铺”看错写并输入正确词语。图片题在两个游戏中都采用“看图纠错”，输入完整的正确词语，避免仅凭印刷体和手写体的外观猜答案。
5. 可选每轮 5、10、20 题，题目不足时只出已有题目，不重复凑数。优先未掌握词语，再按连续答对次数少、累计错误次数多排序；相同优先级随机。
6. 答题后显示答案与提示；连续答对 3 次算“已掌握”，答错重置连续次数。这个指标仅用于游戏，不代替实际学习评估。错误词语可在结算后单独重练。
7. “成长记录”可查看每词掌握度与最近 50 轮练习。提前结束的已答进度会保留。

## 备份与导入

“导出备份”导出 JSON 文件，包含题目、图片、提示、每词练习进度和最近的练习轮次记录。请定期导出。
“导入题库”可导入导出的文件或下列数组，合并题库，不覆盖已存在的相同正确/错写组合，不重复导入同一进度。导入的新词可恢复其练习进度。每份文件最多 20 MB，题库最多 2000 组，实际可保存数量取决于浏览器空间。示例：

```json
[
  {"correct":"再接再厉","wrong":"再接再励","hint":"继续努力，用厉。"},
  {"correct":"迫不及待","wrong":"迫不急待","hint":"来不及等待。"}
]
```

## 录入无法打出的手写错字

选择“图片”，上传 JPG、PNG 或 WebP，也可在添加/编辑弹窗中直接粘贴截图；原图不超过 10 MB、2400 万像素。建议先将作业照片裁成单个字或词语，图片中的错写内容应与填写的正确词语对应。例如只上传一个错字时，正确写法也填对应的单字。

图片在本机压缩成长边不超过 1280 像素的 JPEG，再预览确认笔画清晰后保存；不会上传到服务器。编辑时会保留原图，可替换或移除，也可以切回文字。修改错写内容或录入方式会重置该题的练习进度；只改记忆提示不会重置。

图片会随 JSON 题库一起导出和恢复；旧版纯文字备份仍可导入。带图片的练习单与下载的独立 HTML 都会内嵌图片，离线也能显示。图片占用浏览器空间，建议定期导出备份；添加或导入保存失败时会回退新增内容并提示，添加弹窗会保留输入以便重试。

## 浏览器空间不足时，改用电脑上的本地文件

页面上方新增“保存位置”。点击“将当前题库存到本地文件”，选择一个 JSON 文件，即将已保存的题目、图片和学习历史写入电脑磁盘，并切换到本地文件模式。以后添加、编辑、删除、导入及答题进度都会自动写入该文件，不再依赖 localStorage 容量。页面会显示正在写入、已保存或失败提示；关闭前请确认显示“已保存到本地文件”。

如果添加图片时遇到浏览器空间不足，添加弹窗会保留输入和图片，并提供“转存到本地文件”入口。先选文件完成迁移，再回到原添加弹窗点“保存到错字本”，将尚未保存的题目也写入文件。

刷新或重新打开网页后，点击“保存位置 → 打开已有本地题库”，选回同一个 JSON 文件继续。新开标签页也请先打开本地文件，不要误把旧浏览器题库当成最新进度。刷新当前文件模式的页面时，会暂时显示空题库并要求重新打开文件，避免自动覆盖磁盘内容。打开已有文件是切换题库，和“导入题库”的合并方式不同；旧版文字备份及含图片的备份均可打开，历史记录缺失时视为空历史。

第一次保存本地文件需要用户选择路径，网页无法静默指定磁盘位置或绕过浏览器权限。若浏览器不支持此功能（如部分手机浏览器），界面会提示并禁用文件按钮，仍可手动“导出备份”下载。直接打开本地文件的支持取决于浏览器策略；若被组织策略禁止，请用支持文件选择接口的桌面浏览器或由本地服务器/HTTPS 打开网页。

文件写入失败时不会显示保存成功，题目输入仍保留，可重新保存或另存文件。答题过程中写入失败的进度保留在页面内，可用“立即保存当前本地文件”重试；未保存时离开页面会有浏览器提示。文件写入按顺序执行，避免同一页的旧快照覆盖新进度。不支持多人/多标签页同时修改同一文件。建议定期通过“导出备份”留一个独立副本，不能将自动保存文件当成历史备份。

可“切回浏览器保存”，空间足够时才会切换并复制当前题库，本地文件保留不删除。原浏览器题库在使用文件模式期间不被自动更新或删除。本地题库最多 2000 组，打开文件上限 200 MB，仍受电脑可用内存、磁盘和浏览器策略限制。

## 数据与边界

- 无外部资源、无 API、无数据上传；题库和记录可保存在当前浏览器 localStorage 或用户选择的本地 JSON 文件中。
- 清理浏览器数据、换浏览器或设备不会自动保留记录；file:// 下存储行为也可能受浏览器策略影响。不要仅依赖浏览器作为唯一备份。
- 当前为单个学习档案；同一浏览器打开同一份页面会共享记录，不支持班级账户或多个学生分别统计。
- 建议一次只在一个页面练习，避免多标签页互相覆盖。
- 正确写法和常见错写各最多 30 字，提示最多 200 字。单字对照容易缺少语境，优先录入完整词语。
- 保存失败会提示导出；损坏或未知版本的本地记录不会被自动覆盖。

## 导出可打印复习练习单

在“我的错字本”点击“导出练习单”。可选全部、待巩固、曾答错或当前筛选结果（包含搜索条件），生成选择题或改错题；题量可选 10、20、40 或全部，题目不足时不重复。

纯文字学生页每页最多 8 题，包含图片的题目范围每页最多 4 题，留出姓名、班级、日期和书写区域。图片题即使选择了选择题格式，也以看图改错题呈现。可勾选教师答案，答案另起一页，记忆提示仅出现在教师答案中；随机题序与选择题选项生成后固定，答案题号保持对应。生成练习单不会更改游戏进度。

在新打开的预览窗口点“打印 / 另存为 PDF”，使用 A4、100% 缩放，并关闭浏览器页眉页脚；只发学生题目时按预览标出的练习页码打印，或生成时取消“附教师答案”。也可点“下载练习单 HTML”，得到不依赖原网页、可离线打开和打印的文件。

如果浏览器拦截新窗口，请允许当前页面弹窗后重试。字较长时可在打印预览中微调缩放，确认分页后再打印。带答案的 HTML 包含答案，请勿直接作为无答案练习发给学生。

## 文件

- index.html：结构与交互弹窗
- styles.css：响应式界面，无在线字体
- app.js：题库、小游戏、进度和导入导出
- images.js：文字/图片切换、手写图片压缩与预览
- storage.js：浏览器保存、本地文件模式、保存状态与失败恢复
- worksheet.js：纸面练习生成、打印预览和离线 HTML 导出
